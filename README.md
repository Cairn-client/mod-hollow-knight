# HKMP on Cairn

A fork of [Extremelyd1/HKMP](https://github.com/Extremelyd1/HKMP), the multiplayer mod for **Hollow Knight**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod's release is published as a pack the launcher installs in the game's Mods folder and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on and the release the pack carries.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Install the Hollow Knight Modding API once with [Lumafly](https://github.com/TheMulhima/Lumafly): it replaces a game file, which Cairn never does.
3. Open Hollow Knight in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
